The effective root [`LICENSE`](../LICENSE) is **MIT, Copyright (c) 2026 Liuyun**. It covers project-owned source and original generated art; third-party components keep their own notices. The former proposal is superseded. No repository was published or license grant attributed to a fabricated Git identity.

All actively configured application icons, favicon, splash and adaptive foreground have been replaced with original geometric gift/light artwork generated by `scripts/create-brand-assets.mjs`. Its SVG and PNG outputs use the established ink-brown/warm-white/amber palette; no supplied artwork, font glyphs or external image pixels are used. The original deterministic paper grain is generated by `scripts/create-paper-grain.mjs`.

Unknown old files remain preserved locally and in earlier snapshots; their permission is not inferred. Use the curated package for public-source preparation rather than uploading the original working directory wholesale.
